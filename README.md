# محول الملفات (File Converter)

يحوّل الصور (png / jpg / webp / bmp / gif / tiff / ico) والفيديو (mp4 / mkv / webm / avi / mov / gif) والصوت (mp3 / wav / flac / aac / ogg / m4a).
واجهة رسومية مع سحب وإفلات، ويشتغل كذلك من سطر الأوامر.

- القائمة تعرض صيغ نفس نوع الملفات فقط (فيديو ← صيغ فيديو، صور ← صيغ صور).
- لو الملف فيديو وتبي الصوت بس: فعّل «استخراج الصوت فقط».
- **رفع الجودة بالذكاء الاصطناعي** (Real-ESRGAN): يرفع الدقة فعلياً ويولّد تفاصيل جديدة، مو مجرد تكبير.

## رفع الجودة: لازم تعرف
- يحتاج كرت شاشة يدعم **Vulkan** (NVIDIA / AMD / Intel حديث). ما فيه وضع معالج.
- النماذج الواقعية والأنمي تدعم ×4 فقط. النموذج السريع يدعم ×2 و×3 و×4.
- الفيديو بطيء جداً: يفكك الفيديو لإطارات، كل إطار يمر على النموذج، ثم يجمّعها مع الصوت الأصلي.
  يحتاج مساحة فاضية كبيرة (الإطارات الناتجة تكبر بمقدار المضاعفة²) والبرنامج يتوقف برسالة إذا المساحة ما تكفي.
- الذكاء الاصطناعي يخمّن تفاصيل: النتيجة أحسن بكثير من التكبير العادي، لكنها مو نسخة أصلية عالية الدقة.

## الحصول على الـ exe
1. ارفع هذي الملفات على مستودع GitHub (تأكد إن مجلد `.github` انرفع).
2. روح تبويب **Actions** وانتظر يخلص البناء.
3. افتح آخر تشغيل ونزّل **FileConverter** من قسم Artifacts، فيه `FileConverter.exe`.

لإصدار رسمي في تبويب Releases: سوّ tag يبدأ بـ `v`، مثل `v1.0`، والـ exe ينرفع تلقائياً.

## التشغيل بدون exe
```
pip install pillow tkinterdnd2
python converter.py
python converter.py -t jpg *.png
python converter.py -t png --upscale 4 صورة.jpg            # رفع جودة صورة
python converter.py -t mp4 --upscale 2 --model fast فيديو.mp4
```
للفيديو والصوت: ffmpeg (`winget install Gyan.FFmpeg`) أو حط `ffmpeg.exe` جنب `converter.py`.
لرفع الجودة: حط مجلد `realesrgan` (فيه `realesrgan-ncnn-vulkan.exe` ومجلد `models`) جنب `converter.py`.
الـ exe الجاهز يحتوي الاثنين داخله.
